# Results

This folder contains the main experimental outputs generated during the validation of the proposed method.
The results include plots, alarm visualisations and figures associated with the experiments reported in the paper.

# Included figures
- covid_italy_figure.png: results for the COVID-19 Italy experiment, showing the actual series, LSTM prediction and detected alarms for Lazio, Campania and Sicily.
- power_dataset_figure.png: results for the Power Demand dataset, showing the real series, prediction, detected alarms, anomalous intervals, prediction error and dynamic threshold.
- space_shuttle_figure.png: results for the Space Shuttle dataset, showing the normal and anomalous regions and the alarms generated in the test region.
